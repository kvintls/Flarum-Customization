# kvin 论坛 — 页面设计约定（Arch BBS / FluxBB 风格）

## 强制公共部分（每一种页面都必须有）
无论是首页、板块列表页(IndexPage)、还是主题详情页(DiscussionPage)，以下公共部分**必须始终存在**，不得删除：

1. **底部页脚**（`#kvin-footer2`：`由 Flarum 提供技术支持 · © kvin 论坛`）
   - 必须在**白卡框内**（和首页一致），带顶部蓝色分隔线并拉满卡片宽度。
   - 这是唯一的强制公共组件。

## 非公共部分（页面专属，不要当成公共组件复制到其它页面）
- **面包屑/工具条那一行**（列表页 `#kv-forumbar`：「首页 » 板块」+「发布新主题」按钮）
  - **仅属于板块列表页**，不是公共部分；不要复制到主题详情页等其它页面。
- 站点顶栏下方那条留白只是间距，不是组件。

## 主区域白卡
- 各页面主区域统一用与首页 `.CategoriesPage-content` 相同的白卡：白底 / `1px solid #c9cfd6` 边框 / 无圆角 / 无阴影 / 16px 内边距 / 容器 `max-width:1320px; width:94%` 居中。

## 帖子（主题详情页）布局 = 方案A「上下结构」
- 每帖一个带边框的块，顶部灰色 header：
  - **上边**：小头像(≈26px 方块) + 用户名 + 徽章(楼主等，紧跟用户名不留空) + 时间；右侧 `#楼层`。
  - **下边**：帖子正文。
- 不使用 Arch 原版的左侧作者信息 column。

## 头像
- 需要一套默认头像图片，用户注册后自动分配（见部署说明，使用 Flarum 扩展实现）。
